# We Found You - AdCamp ARG

An interactive Alternate Reality Game (ARG) web experience built with React, TailwindCSS, and Vite. 
This project is an immersive digital journey leading up to AdCamp, exploring themes of visual communication and hidden messaging.

## Features
- Immersive terminal-style interface
- Glitch effects and interactive puzzles
- Smooth navigation between ARG levels
- Fully responsive design

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the app:
   ```bash
   npm run dev
   ```

## Deployment Configuration
Note: To capture user submissions on the final 'Found' page, update the Formspree endpoint in `src/pages/Found.tsx` with your own Formspree ID.
